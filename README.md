# AttendTrack

**AttendTrack** — консольное приложение для учёта посещаемости занятий студентами. Проект автоматизирует процессы работы с группами, расписанием и отметками посещаемости вместо ведения бумажного журнала.

## Описание проекта

Система предназначена для автоматизации учёта посещаемости занятий студентами в учебном заведении. Она охватывает учебные группы, студентов, преподавателей, дисциплины, расписание занятий и записи о посещаемости (`присутствует` / `отсутствует` / `отсутствует по уважительной причине`).

> Подробная постановка задачи — в отчёте по лабораторной работе №1: [`docs/Отчет_ЛР1_Учет_посещаемости.docx`](docs/Отчет_ЛР1_Учет_посещаемости.docx)

## Пользователи системы

| Роль | Возможности |
|---|---|
| **Администратор** | управляет группами, расписанием и учётными записями пользователей |
| **Преподаватель** | отмечает посещаемость, просматривает журнал группы, формирует отчёты |
| **Студент** | просматривает свою посещаемость, подаёт заявку на уважительную причину |

## Архитектура

Проект построен на классической **трёхуровневой (слоистой) архитектуре**:

1. **Presentation Layer** — консольный интерфейс (`src/main.cpp`)
2. **Business Logic Layer** — проверки и расчёты (`src/AttendanceService.*`)
3. **Data Access Layer** — хранение данных (`src/Repository.*`)

Такое разделение позволяет менять способ хранения данных (например, перейти на SQLite в ЛР №3), не затрагивая бизнес-логику и интерфейс.

## Технологии

- **Язык:** C++17
- **Сборка:** g++ / любой компилятор с поддержкой C++17
- **Диаграммы:** PlantUML, draw.io

## Сборка и запуск

```bash
cd src
g++ -std=c++17 -Wall -o ../attendtrack main.cpp Repository.cpp AttendanceService.cpp
cd ..
./attendtrack
```

Пример работы программы (тестовые данные создаются автоматически при запуске):

```
===== AttendTrack — учёт посещаемости =====
1. Добавить студента
2. Добавить занятие
3. Отметить посещаемость
4. Показать посещаемость по занятию
5. Показать процент посещаемости студента
6. Сформировать отчёт по группе (CSV)
0. Выход
```

## База данных

Проект использует **SQLite**. Схема и тестовые данные — в файле [`db/schema.sql`](db/schema.sql).

| Таблица | Описание | Связь |
|---|---|---|
| `Groups` | учебные группы | 1 группа → N студентов, 1 группа → N занятий |
| `Students` | студенты | принадлежит одной группе |
| `Lessons` | занятия | принадлежит одной группе |
| `Attendance` | отметки посещаемости | связывает Students и Lessons (M:N через 1:N + 1:N) |

Создать базу данных из схемы:

```bash
sqlite3 attendtrack.db < db/schema.sql
```
